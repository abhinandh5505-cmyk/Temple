# SREERANGANADHA — Hero recreation

This React + Vite project recreates the supplied hero reference without changing its visual composition. The supplied screenshot is used as the hero artwork so its typography, temple, clouds, colours, water reflection, and proportions remain exactly as provided.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The hero artwork is stored locally at `public/images/hero-reference.jpg`; the sacred temple interior artwork is stored locally at `public/images/temple-interior.jpg` (`public/images/interior-reference.jpg`); no external image URLs are required. Both artworks are 100% preserved in their exact composition.
